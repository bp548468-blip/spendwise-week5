# SpendWise - JavaScript Foundation

A simple budget tracker that asks for name, monthly budget, and expenses, then calculates total, balance, percentage spent, and budget status.

## Features
- Uses variables, prompt(), and console.log()
- Uses functions: calculateTotalExpenses, calculateRemainingBalance, calculatePercentageSpent, getBudgetStatus
- Uses loop (for) and array of expense objects
- Uses if/else for budget status
- Displays results on page and in console

## How to Run
1. Open index.html in browser
2. Answer the prompts (name, budget, expenses)
3. Press Ctrl + Shift + J to see results in Console
4. Click "Start Again" to run again

## Files
- index.html - structure
- style.css - styling
- script.js - logic
